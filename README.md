# Nebius × Kimi-K3 — APAC Landing Page

Landing page promoting Kimi-K3 availability on Nebius Token Factory, targeting enterprise
technical decision makers and developers in Asia Pacific.

## Structure
Single self-contained file: `index.html` (inline CSS, no build step, Google Fonts only external dependency).

## Deploy with GitHub Pages
1. Push this repo to GitHub
2. Repo → Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)`
3. Page goes live at `https://<username>.github.io/<repo>/`
